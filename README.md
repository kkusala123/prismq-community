# 棱题 · PrismQ Community（开源自托管 AI 刷题与智能组卷平台）

一套开箱即用、完全开源自托管的极简 AI 刷题与智能组卷平台。支持响应式 Web、PWA 与 Android 原生客户端（**支持在客户端自由切换与连接你的自建服务器**）、DeepSeek AI 题目星级与难度评级、动态均衡组卷、规范化 `kaoshibao.qbank.v1` 试题数据契约、AI 智能导题与校验工作台，以及 Docker Compose + PostgreSQL 独立容器一键部署。

---

## 核心功能亮点

1. **自托管优先 & Android 客户端支持自定义服务器**：
   - Android 客户端支持在登录页和「系统设置」中自由填写你的自建服务端地址（同时支持 HTTP 内网调试地址与 HTTPS 公网域名）。
   - **可选 GitHub APK 更新推送**：服务端默认关闭，如你的团队需要自动分发自构建安装包，可在 `.env` 中设置 `APP_UPDATE_ENABLED=true` 与你自己的 `GITHUB_REPO`。
2. **行业规范数据契约 & 多格式智能导题**：
   - 统一 `kaoshibao.qbank.v1` JSON Schema（`GET /api/import/schema.json`）与标准文本规范，支持 `.xlsx` / `.xls` / `.csv` / `.docx`（Word）/ `.pdf` / `.txt` / `.md` / `.json` / `.gift`（Moodle GIFT）与 Aiken 格式。
   - **左右分栏智能录题工作台**：左侧带行号标准文本编辑器，右侧实时预览标准考题卡片、自动区分阻塞错误与建议警告、点击报错行号直达定位。
3. **DeepSeek / OpenAI 兼容 AI 引擎（管理员权限严格隔离）**：
   - **AI 智能导题（SSE 流式进度）**：将杂乱试卷、PDF 文本或讲义一键清洗为规范标准题库格式，支持忠实保留原题措辞、自动补全解析、文末集中答案区对照识别及一键 AI 修复异常题。
   - **AI 智能评级 & 按主题出题 & 深度讲题**：支持对题库进行 AI 难度与星级评级，并在组卷时按难度均衡动态抽题。
   - **权限隔离**：全局 API 地址、全局 Key 与模型配置**仅系统管理员可见与管理**；普通成员仅可配置自己的个人 API Key（或由管理员选择是否开放共享使用权限，且绝不暴露全局服务端点与密钥信息）。
4. **全模式刷题、背题与智能错题本**：
   - 顺序续刷（记忆断点）、随机乱序（含选项乱序）、章节专项、题型专项、**背题模式（答案与解析直显）**、**斩题过滤**、收藏夹、个人笔记与桌面快捷键。
   - 答错自动进入错题本，可自定义“连续答对 N 次自动移出错题本”（默认 3 次）；支持全局搜题、导出 Excel 及 A4 打印视图。
5. **多用户与组织在线考试系统**：
   - 公共题库广场一键刷题或克隆；发布在线考试生成 8 位分享码，支持入场口令、限制作答次数、防切屏监测、倒计时自动交卷与组织者排行榜/简答题人工调分看板。

## 一键部署到 Docker 服务器

```bash
# 1. 复制环境变量配置并修改数据库密码与 JWT 密钥
cp .env.example .env

# 2. 启动 PostgreSQL 17 容器与棱题 · PrismQ 应用容器
docker compose up -d --build

# 3. 查看服务状态
docker compose ps
```

默认访问地址：`http://<服务器IP>:3000`

**首次启动说明**：系统不内置任何测试账号。首次打开页面时将自动引导创建第一个账号，**第一个注册的用户会自动成为系统管理员（admin）**，后续注册的用户均为普通成员（member）。
